# CN-057-9-4 課題仕様書

## 1. 目的・学習内容

- **【目的】:** JavaScriptで動的に生成したHTML（テーブル）をkintoneのカスタマイズビュー画面に表示し、CSSフレームワーク（Materialize）を適用できるようになること。

---

## 2. 使用アプリ

以下のアプリを研修環境に取り込んで利用すること。  
*(※ アプリテンプレートファイル：`予実管理.zip`)*

- **15** 【入社前研修】予実管理

---

## 3. 機能要件

### ■ 要件①: カスタマイズビューへの予実管理情報の表示
一覧（カスタマイズ）**「予算達成率」**に、以下の計算値・情報が入った表を表示させること。

- **予算No**（フィールドの値）
- **年度**（フィールドの値）
- **拠点**（フィールドの値）
- **予算**（フィールドの値）
- **実績**（フィールドの値）
- **差異:** `[実績] - [予算]` の計算値
- **達成率:** `[予算]` に対する `[実績]` の達成率を **％表示**（※ 小数点第3位を切り捨て）

### ■ 要件②: CSSフレームワーク (Materialize) の適用
- 要件①で作成した表に Materialize の Table スタイル (`striped`) を適用すること。
- 予算達成率が **100％未満** の場合に、達成率セルのスタイルを変更すること。
  - **背景色:** `red lighten-5`
  - **文字色:** `red-text text-accent-4` (Color クラス)

---

## 4. 設計仕様 & 設定手順

### ■ 要件① 設計仕様
1. 一覧名「予算達成率」を使用する。（※ 設定画面で以下の確認事項に当てはまらない場合は修正すること）
   - レコード一覧の表示形式が **「カスタマイズ」** になっていること。
   - **「ページネーションを表示する」** にチェックが入っていること。
   - HTMLカスタマイズ欄に `<div id="customize"></div>` が入力されていること。
2. `event.viewName` または `viewId` を用いて一覧を判定し、「予算達成率」画面でのみプログラムを動作させる。
3. `event.records` の値を用いて Table HTML を動的に作成し、`id="customize"` 要素内に表示させる。

### ■ 要件② 設計仕様
1. 設定画面の「JavaScript / CSSでカスタマイズ」で以下の CSS (CDN) を**「URLを指定して追加」**で読み込む。
   - `https://cdnjs.cloudflare.com/ajax/libs/materialize/1.0.0/css/materialize.min.css`
2. 生成した HTML の `<table>` 要素および `<td>` セルに必要な Materialize クラス名（`striped`, `red lighten-5`, `red-text text-accent-4` 等）を付与する。

## 5. kintone 開発専門家による設計・実装アドバイス

実務で堅牢なカスタマイズビューを実装する際、専門家が必ず配慮する設計ポイントです。

- **ゼロ除算 (Division by Zero) の防止:**  
  予算が未入力または `0` のレコードが存在した場合に除算を行うと、JavaScript上では `Infinity` や `NaN` が返り、UI表示が壊れる原因になります。必ず `if (budget > 0)` のようなガード文を入れ、`0`除算を未然に防ぐ実装が必要です。
- **クロスサイトスクリプティング (XSS) 対策の徹底:**  
  動的にHTML文字列を構築して `innerHTML` へ流し込む際、ユーザーが自由に入力できる「拠点」などのテキストフィールド値をエスケープせずに直接結合すると、任意のスクリプトが実行されるXSS脆弱性が生じます。実務では必ず `escapeHtml()` のようなヘルパー関数を通す必要があります。
- **データ件数とページネーションの連動:**  
  `event.records` には、レコード一覧画面の「現在のページに表示されている件数（通常20件〜100件）」のみが入ります。ページを切り替えたり一覧を絞り込んだりするたびに `app.record.index.show` イベントが再発火し、ビューが自動的に最新データで再レンダリングされる仕組みを理解して設計してください。
- **使い勝手 (UX) の向上:**  
  数値を画面上にプレーンテキストで表示するのではなく、金額に `toLocaleString()` を適用して3桁カンマ区切りにし、末尾に「円」や「%」などの単位を明記することで、一目で状況が判断できる高品質なビジネス向け画面になります。

## 6. 導入・操作手順ガイド

本カスタマイズプログラムを「予実管理」アプリに適用し、動作確認するための手順です。

### ステップ 1: カスタマイズビューの設定 (kintoneアプリ側)
1. **「【入社前研修】予実管理」** アプリを開き、設定画面（歯車マーク ⚙）を開きます。
2. **「一覧」タブ** を開き、**「予算達成率」** という名前の一覧を新規作成（または編集）します。
3. レコード一覧の表示形式で **「カスタマイズ」** を選択します。
4. HTML記述欄に以下を入力します：
   ```html
   <div id="customize"></div>
   ```
5. **「ページネーションを表示する」** にチェックを入れます。
6. 一覧の設定を保存します。

### ステップ 2: CSS (CDN) と JavaScript ファイルの設定
1. 下記の「7. 模範解答コード」をコピーし、`budget_achievement.js` (UTF-8 BOMなし) として保存します。
2. アプリ設定の **「JavaScript / CSSによるカスタマイズ」** を開きます。
3. **「PC用CSSファイル」** の **「URLを指定して追加」** を選択し、以下のURLを入力して追加します：
   `https://cdnjs.cloudflare.com/ajax/libs/materialize/1.0.0/css/materialize.min.css`
4. **「PC用JavaScriptファイル」** の **「ファイルを選んで追加」** を選択し、作成した `budget_achievement.js` をアップロードします。
5. 設定を保存し、画面右上の **「アプリを更新」** をクリックします。

### ステップ 3: 動作確認
1. 予実管理アプリの一覧ドロップダウンから **「予算達成率」** を選択します。
2. Materialize のストライプ表が表示され、予算・実績・差異・達成率(%) が正しく計算されていることを確認します。
3. 達成率が 100% 未満のセルが淡い赤色の背景（`red lighten-5`）かつ濃い赤文字（`red-text text-accent-4`）でハイライト表示されていることを確認します。

## 7. 模範解答コード (JavaScript / async/await 対応・防御的設計版)

```javascript
/**
 * 課題名: CN-057-9-4 予実管理 カスタマイズビュー＆MaterializeCSS表示
 * 対象アプリ: 【入社前研修】予実管理 (AppID: 27)
 */
(function() {
  'use strict';

  // レコード一覧画面表示イベント
  kintone.events.on('app.record.index.show', function(event) {
    // カスタマイズビューの要素を取得
    const container = document.getElementById('customize');
    if (!container) {
      return event;
    }

    // 「予算達成率」一覧の場合のみ実行 (ビュー名によるフィルタ)
    if (event.viewName !== '予算達成率') {
      return event;
    }

    const records = event.records;
    if (!records || records.length === 0) {
      container.innerHTML = '<p class="flow-text" style="padding: 20px;">表示対象の予実レコードがありません。</p>';
      return event;
    }

    // Materialize の striped テーブルクラスを適用
    let html = '<table class="striped responsive-table highlight">';
    html += '<thead>';
    html += '<tr>';
    html += '<th>予算No</th>';
    html += '<th>年度</th>';
    html += '<th>拠点</th>';
    html += '<th>予算</th>';
    html += '<th>実績</th>';
    html += '<th>差異</th>';
    html += '<th>達成率</th>';
    html += '</tr>';
    html += '</thead>';
    html += '<tbody>';

    // 各レコードをループ処理
    records.forEach(function(rec) {
      const budgetNo = rec.予算No ? rec.予算No.value : '';
      const year = rec.年度 ? rec.年度.value : '';
      const branch = rec.拠点 ? rec.拠点.value : '';
      const budget = rec.予算 ? Number(rec.予算.value) : 0;
      const actual = rec.実績 ? Number(rec.実績.value) : 0;

      // [差異] = [実績] - [予算]
      const diff = actual - budget;

      // [達成率] = ([実績] / [予算]) * 100
      // 予算が0または空欄の場合のゼロ除算 (Division by Zero) を防止
      let ratePercent = 0;
      if (budget > 0) {
        const rawRate = (actual / budget) * 100;
        // 小数点第3位以下を切り捨て (Math.floor を利用)
        ratePercent = Math.floor(rawRate * 100) / 100;
      }

      // 達成率が100%未満の場合、警告用 Materialize カラークラスを付与
      // 背景色: red lighten-5 / 文字色: red-text text-accent-4
      let rateClass = '';
      if (ratePercent < 100) {
        rateClass = 'red lighten-5 red-text text-accent-4';
      }

      html += '<tr>';
      html += '<td>' + escapeHtml(budgetNo) + '</td>';
      html += '<td>' + escapeHtml(year) + '</td>';
      html += '<td>' + escapeHtml(branch) + '</td>';
      html += '<td>' + budget.toLocaleString() + ' 円</td>';
      html += '<td>' + actual.toLocaleString() + ' 円</td>';
      html += '<td>' + (diff >= 0 ? '+' : '') + diff.toLocaleString() + ' 円</td>';
      html += '<td class="' + rateClass + '" style="font-weight: bold;">' + ratePercent.toFixed(2) + ' %</td>';
      html += '</tr>';
    });

    html += '</tbody>';
    html += '</table>';

    // 生成したテーブルHTMLを表示領域へ設定
    container.innerHTML = html;

    return event;
  });

  // クロスサイトスクリプティング (XSS) 防止用 HTML エスケープ関数
  function escapeHtml(str) {
    if (!str) return '';
    return String(str)
      .replace(/&/g, '&amp;')
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;')
      .replace(/"/g, '&quot;')
      .replace(/'/g, '&#39;');
  }
})();
```

## 8. コードの解説

1. **`escapeHtml` によるセキュリティの確保**
   - 文字列型のユーザー入力フィールド（予算No、年度、拠点）の値を表示する際、HTML特殊文字を実体参照に置換してレンダリングすることで、悪意あるコードの混入を防ぐ安全な設計にしています。
2. **`Math.floor(rawRate * 100) / 100` による正確な切り捨て処理**
   - 「小数点第3位以下を切り捨て」に対応するため、達成率を100倍した値で `Math.floor()` を実行した後に100で割ることで、数学的に正確な切り捨て計算を行っています。
3. **`budget > 0` によるゼロ除算ガード**
   - 新規登録直後などで予算が未入力（あるいは `0`）になっているレコードが含まれていても、プログラムが `NaN` や `Infinity` を出力してクラッシュしないよう、ガードブロックを設けています。
4. **Materialize CSS スタイルの適用**
   - `striped highlight` クラスでホバー効果としま模様の表にし、達成率100%未満の行（`ratePercent < 100`）のみ `red lighten-5 red-text text-accent-4` をセルへ動的に追加しています。
