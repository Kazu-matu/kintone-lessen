# kintone × MCP (Model Context Protocol) 設定・活用ガイド

このガイドでは、AI（Claude Desktop や Antigravity IDE など）と kintone を連携させ、kintone のデータやローカルのドキュメントをAIに直接読み込ませる「MCP（Model Context Protocol）」の仕組み、設定内容、および具体的な使い方を初学者向けに分かりやすく解説します。

---

## 1. MCP（Model Context Protocol）とは？

MCPとは、**「AIが外部のツールやデータと安全に会話するための共通ルール（プロトコル）」**です。
通常、AIはインターネット上の一般的な知識しか持っていませんが、MCPを使うことで、以下のようなことができるようになります。

* **kintone内のデータ操作**: 「アプリから顧客リストを取得して」「今月の売上レコードを追加して」と指示するだけで、AIが自動でkintone APIを呼び出して実行します。
* **ローカルファイルの参照**: PC内の特定のフォルダ（設計書やプログラムコードなど）をAIが直接読み込み、その内容に基づいた正確な回答やコード生成を行います。

---

## 2. 今回設定した内容

お使いの環境には、以下の2つの連携機能（MCPサーバー）が設定されています。

### ① kintone データ連携 (`kintone`)
* **役割**: kintone上のアプリ構造の取得、レコードの追加・更新・削除・検索をAIが代行します。
* **技術的な仕組み**: サイボウズ公式の `@kintone/mcp-server` を `npx` コマンド経由で呼び出しています。接続に必要なkintoneのURLや認証情報は安全に設定ファイル内に保存されています。

### ② ローカルファイル連携 (`filesystem`)
* **役割**: 現在の開発プロジェクトフォルダ（`z:\kintone`）の中身をAIが直接読み書きできるようにします。
* **技術的な仕組み**: MCP公式の `server-filesystem` を使用し、指定したフォルダ内のみへのアクセス権限をAIに与えています。

---

## 3. 設定ファイルの中身（参考）

設定情報は、お使いの環境の `claude_desktop_config.json`（Claude Desktop用）および `mcp_config.json`（Antigravity IDE用）に以下のように書き込まれています。

```json
{
  "mcpServers": {
    "kintone": {
      "command": "npx",
      "args": [
        "-y",
        "@kintone/mcp-server"
      ],
      "env": {
        "KINTONE_BASE_URL": "https://kazu-lab.cybozu.com",
        "KINTONE_USERNAME": "kazufumi0707@gmail.com",
        "KINTONE_PASSWORD": "matu1189"
      }
    },
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "z:/kintone"
      ]
    }
  }
}
```

## 4. 具体的な利用方法（プロンプト例）

設定が完了すると、AIチャット画面で以下のような指示を出すだけで、AIが自動的に裏側で設定されたMCPツールを呼び出します。

### kintone のデータを操作・確認したいとき

AIに対して、人間の言葉で指示を出すだけで実行してくれます。

* **データの検索・取得**:
  > 「アプリID 120 のアプリから、ステータスが『未処理』のレコードを一覧で取得して、表にまとめてください。」
* **レコードの追加・更新**:
  > 「案件管理アプリ（ID: 15) に、顧客名『サイボウズ株式会社』、金額『500,000円』で新しいレコードを追加して。」
* **アプリの設定確認**:
  > 「予算管理アプリのフィールド一覧（フォーム設計）を教えて。」

### ローカルの仕様書やコードを読み込ませたいとき

プロジェクト内のドキュメント（`z:\kintone\docs` 内のMarkdownなど）を読み込ませて、開発のサポートを依頼できます。

* **単一の仕様書の読み込みとコード作成**:
  > 「`docs/予実管理仕様.md` の内容を読み込んで、その仕様を満たすためのkintoneカスタマイズ用JavaScriptコード（`budget_achievement.js`）を作成してください。」
* **複数のドキュメントを横断して参照・適用する**:
  > 「`docs/予実管理仕様.md` の機能要件を満たしつつ、`.agents/AGENTS.md` に記載されているプログラムヘッダーのコメント規則（版数、作成日、ツール名など）に従ってコードを作成してください。」
* **既存コードのレビュー**:
  > 「`src/課題/cn-057-9-4.js` のコードを読み込んで、エラーハンドリングに不備がないかチェックして。」

### Web上の外部ドキュメント（API仕様書など）を参照させたいとき

FetchやWeb Search用のMCPサーバーが有効になっている場合、インターネット上の最新ドキュメントを直接参照させることができます。

* **特定のWebドキュメントURLを読み込ませる**:
  > 「`https://cybozu.dev/ja/kintone/docs/apis/rest/records/get-records/` にあるkintoneのレコード取得APIのドキュメントを読み込んで、クエリの書き方の制限（上限値など）を教えてください。」
* **最新の仕様を検索させて実装に活かす**:
  > 「kintoneのルックアップフィールドにAPI経由で値をコピーする際の最新の制限事項についてWebで検索し、それを踏まえたJavaScriptの実装例を作ってください。」

## 5. トラブルシューティング（動かないときのチェックリスト）

もしAIが「kintoneのデータが見つかりません」や「ツールを実行できません」といったエラーを出した場合、以下の点を確認してください。

1. **アプリ（Claude Desktopなど）を再起動しましたか？**
   * 設定ファイルを書き換えた後、アプリケーションを完全に終了（タスクトレイ等からQuit）して再起動しないと、新しい設定が読み込まれません。
2. **Node.js はインストールされていますか？**
   * コマンドプロンプトやターミナルで `node -v` と入力し、バージョンが表示されるか確認してください。
3. **パスワードやドメインは合っていますか？**
   * kintoneのログインパスワードを変更した場合などは、設定ファイル（`mcp_config.json` 等）の `KINTONE_PASSWORD` 部分を書き換える必要があります。
4. **アクセス許可されたフォルダの範囲内ですか？**
   * `filesystem` サーバーは `z:/kintone` 内のみアクセス可能です。Cドライブ直下など、許可されていない場所にあるファイルをAIに読ませることはできません。
