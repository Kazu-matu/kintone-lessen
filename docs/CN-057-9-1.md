# CN-057-9-1 課題仕様書

## 1. 学習内容 & 目的

- **【目的】:** サブテーブル（フィールドコード: `受注明細Table`）の行毎にループ処理を行い、別アプリ（受注明細）へレコードを新規登録（POST）できるようになること。

---

## 2. 使用アプリ

以下のアプリを研修環境に取り込んで利用すること。  
*(※ 上記のアプリのテンプレートは、本レコードの添付ファイルフィールドに保存されている。ファイル名: `受注管理_受注明細_顧客マスタ_商品マスタ.zip`)*

- **11** 【入社前研修】受注管理
- **12** 【入社前研修】受注明細
- **13** 【入社前研修】顧客マスタ
- **14** 【入社前研修】商品マスタ

---

## 3. 機能要件

### ■ 要件① (概要)
- **処理概要:** 受注管理アプリのサブテーブル（`受注明細Table`）の各行を分けて、受注明細アプリにレコード新規作成する（テーブル展開）。
- **画面表示:** 詳細画面上に「テーブル展開#1」というボタンを表示する。
- **実行トリガー:** 上記ボタンがクリックされた時に、テーブル展開を実行する。
- **コピー対象フィールド（受注管理アプリ → 受注明細アプリ）:**
  - `受注管理No` -> `受注番号`
  - `受注日` -> `受注日`
  - `顧客コード` -> `顧客コード`
  - `数量` -> `数量`
  - `小計` -> `小計`
  - 商品マスタ項目およびテーブル内項目：
    - `商品コード` -> `商品コード_0`
    - `カテゴリ` -> `カテゴリ` （※2026-08-05 追加要件）
    - `商品名` -> `商品名` （※2026-08-05 追加要件）
    - `販売単価` -> `単価` （※2026-08-05 追加要件）

### ■ 要件② (設計仕様 & 実装詳細)

> [!NOTE]
> ※ 記載されている設計仕様は一例です。要件が満たせれば他の実装方法でも構いません。  
> ※ 学習のため `@kintone/rest-api-client` は使用せず実装してください。

#### 【行見出し 1】 ボタン設置仕様
- `kintone.app.record.getHeaderMenuSpaceElement()` を用いてボタンを設置する。
- 設置したボタンにクリックイベントを設定する。
- *(JavaScript、jQuery どちらを使用してもOK)*

#### 【行見出し 2】 テーブル展開処理手順
1. `event.record` を用いてレコードの情報を取得する。
2. レコード内のサブテーブル（`受注明細Table`）の値を取得する。
3. 上記で取得したテーブル各行から受注明細アプリに登録する値を取り出し、登録用パラメータを作成する。
4. `/k/v1/records.json`（POST）を用いて受注明細アプリにレコードを新規作成する。

## 4. 補足 & 注意事項

- **更新対応:** 本課題では、更新処理への対応は不要。明細アプリに重複登録されてOK。
- **連携方向:** コピーの方向は「受注管理アプリ → 明細管理アプリ」への片方向とする。（つまり、明細管理アプリが変更されても受注管理アプリへ反映する必要はない）
- **API制限についての考慮:** 下記のAPI制限については本課題では考慮しない。
  - POST：一度に登録できるレコードは 100 件まで
  - PUT：一度に更新できるレコードは 100 件まで
  - GET：一度に取得できるレコードは 500 件まで
- **キー設計の注意:** `受注管理No` にレコード番号を用いているが、実務ではユニークキーにレコード番号を使用することはない。（アプリ移行時に問題が発生するため）

## 5. 導入・操作手順ガイド

本カスタマイズプログラムを受注管理アプリに適用し、実行確認するための手順です。

### ステップ 1: JavaScriptファイルの作成
1. 下記の「6. 模範解答コード」をすべてコピーします。
2. テキストエディタ（VS Codeやメモ帳等）に貼り付け、文字コード **UTF-8 (BOMなし)** で `table_expand_1.js` という名前で保存します。

### ステップ 2: kintoneアプリへの設定
1. **「【入社前研修】受注管理」** アプリを開きます。
2. 画面右上の歯車マーク ⚙ （設定）をクリックします。
3. **「設定」タブ ＞ 「カスタマイズ／サービス連携」 ＞ 「JavaScript / CSSによるカスタマイズ」** を選択します。
4. 「PC用JavaScriptファイル」の **「ファイルを選んで追加」** をクリックし、作成した `table_expand_1.js` をアップロードします。
5. 画面左上の **「保存」** ボタンをクリックします。
6. 画面右上の **「アプリを更新」** ボタンをクリックし、設定を適用します。

### ステップ 3: 動作確認
1. 受注管理アプリでテストレコードの詳細画面（`app.record.detail.show`）を開きます。
2. ヘッダー領域に表示された **「テーブル展開#1」** ボタンをクリックします。
3. 成功アラートが表示されたら、「受注明細」アプリ（AppID: 12）を開き、サブテーブルの各行が独立したレコードとして登録されていることを確認します。

## 6. 模範解答コード (JavaScript / async/await 版)

```javascript
/**
 * 課題名: CN-057-9-1 サブテーブル展開#1（新規一括登録）
 * 対象アプリ: 【入社前研修】受注管理 (AppID: 11)
 */
(function() {
  'use strict';

  // 転送先「受注明細」アプリのID
  const DETAIL_APP_ID = 12;

  /**
   * レコード詳細画面が表示されたときに実行されるイベントハンドラ。
   * 詳細画面に「テーブル展開#1」ボタンを設置します。
   * 
   * @param {Object} event kintoneのイベントオブジェクト
   * @returns {Object} イベントオブジェクト
   */
  kintone.events.on('app.record.detail.show', function(event) {
    const record = event.record;

    // ヘッダーメニュー領域の取得
    const headerMenuEl = kintone.app.record.getHeaderMenuSpaceElement();
    if (!headerMenuEl || document.getElementById('btn_table_expand_1')) {
      return event; // すでにボタンが存在する場合は何もしない
    }

    // ボタンエレメントの生成とスタイリング
    const btn = document.createElement('button');
    btn.id = 'btn_table_expand_1';
    btn.innerText = 'テーブル展開#1';
    btn.className = 'kintoneplugin-button-normal';
    btn.style.margin = '10px';

    /**
     * ボタンがクリックされたときに実行される非同期処理。
     * サブテーブルのデータを取得し、受注明細アプリへ一括登録（POST）します。
     * 
     * @returns {Promise<void>}
     */
    btn.addEventListener('click', async function() {
      // サブテーブルの取得
      const subtable = record.受注明細Table ? record.受注明細Table.value : [];
      if (!subtable || subtable.length === 0) {
        alert('展開対象の明細行（サブテーブル）が存在しません。');
        return;
      }

      /**
       * サブテーブルの各行から受注明細アプリ用の登録データを生成するコールバック関数。
       * 
       * @param {Object} row サブテーブルの1行分のデータ
       * @returns {Object} 登録用レコードオブジェクト
       */
      const recordsToPost = subtable.map(function(row) {
        return {
          '受注番号': { value: record.受注管理No.value },
          '受注日': { value: record.受注日.value },
          '顧客コード': { value: record.顧客コード.value },
          '商品コード_0': { value: row.value.商品コード.value },
          'カテゴリ': { value: row.value.カテゴリ.value }, // 2026-08-05 追加要件
          '商品名': { value: row.value.商品名.value },     // 2026-08-05 追加要件
          '単価': { value: row.value.販売単価.value },     // 2026-08-05 追加要件
          '数量': { value: row.value.数量.value },
          '小計': { value: row.value.小計.value }
        };
      });

      // API実行と例外処理
      try {
        // kintone REST APIで一括登録(POST)
        const resp = await kintone.api(
          kintone.api.url('/k/v1/records.json', true),
          'POST',
          { app: DETAIL_APP_ID, records: recordsToPost }
        );

        alert('受注明細アプリへ ' + resp.ids.length + ' 件の明細展開登録が完了しました！');
      } catch (err) {
        console.error('明細展開エラー:', err);
        alert('エラーが発生しました: ' + (err.message || JSON.stringify(err)));
      }
    });

    // ヘッダーエリアにボタンを追加
    headerMenuEl.appendChild(btn);
    return event;
  });
})();
```

## 7. コードの解説

1. **`kintone.app.record.getHeaderMenuSpaceElement()`**
   - レコード詳細画面の上部メニュー領域のDOM要素を取得します。重複生成防止のため `document.getElementById('btn_table_expand_1')` でチェックを行います。
2. **`subtable.map()` によるデータマッピング**
   - `record.受注明細Table.value` の配列をループ処理し、親の `受注管理No` や `受注日` などの共通ヘッダー情報と、テーブル行個別の `商品コード`, `数量`, `小計` を1つのオブジェクトとして整形します。
3. **`async / await` による非同期API呼び出し**
   - `kintone.api()` に `await` を付与することで通信結果を同期待機し、成功時は `resp.ids` から作成されたレコードIDの配列を取得します。
4. **`try ~ catch` によるエラー制御**
   - 必須フィールドの漏れや通信エラー発生時は `catch` ブロックでエラーをキャッチし、ユーザーに分かりやすくアラート表示します。
