# プロジェクト別エージェントルール (Project Rules)

本プロジェクトにおける開発・保守を行う際、常に従うべき追加ルールです。

## 1. ソースコードのヘッダーコメント規則
新規作成または修正を行うすべてのプログラムソースコード（JavaScript, CSS 等）の先頭には、必ず以下のメタ情報をコメントとして記載してください。

- **版数 (Version)**
- **作成日 (Created Date)**
- **更新日 (Updated Date)**
- **作成者 (Author)**
- **修正者 (Modifier)**
- **ツール (Tool)**

### フォーマット例 (JavaScript):
```javascript
/**
 * 課題名: [課題ID・名称]
 * 版数: X.X.X
 * 作成日: YYYY-MM-DD
 * 更新日: YYYY-MM-DD
 * 作成者: [作成者名]
 * 修正者: [修正者名]
 * ツール: [使用したAIエージェントツール名]
 */
```
